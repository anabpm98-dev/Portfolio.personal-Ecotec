# Portafolio Personal

Estudiante: Pincay Mora Ana Belén

## Descripción

Portafolio personal desarrollado como parte de la asignatura Programación de Sistemas Web
(Actividad Integradora 1). 
Presenta mi perfil, habilidades, proyectos y una sección de contacto,
mediante una página principal y una página de detalle para cada proyecto.

## Tecnologías utilizadas

- HTML5 (etiquetas semánticas: header, nav, main, section, article, footer)
- CSS3 (variables CSS, Flexbox, efectos hover, media queries)
- Git y GitHub

## Estructura del proyecto

portafolio-personal/
├── index.html
├── Ticketing.html
├── Streaming.html
├── Access-Control.html
├── styles.css
├── README.md
└── img/

## Instrucciones para visualizar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Hacer doble clic en "index.html" para abrirlo en un navegador.
